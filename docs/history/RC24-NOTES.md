# HistoDaily RC24 — Premium Home

Cette release reconstruit uniquement l'accueil pour augmenter fortement l'impact visuel sans réintroduire la surcharge qui avait été critiquée.

- L'expédition du jour devient une affiche éditoriale plein visuel avec véritable illustration embarquée quand la discipline dispose d'un artwork.
- Le texte est déplacé dans le bas de l'image avec vignettage lisible, grande typographie serif et CTA unique.
- La route Expédition → Cours → Quiz reste visible mais discrète.
- Sous le hero, une seule prochaine action est affichée. Une révision due est prioritaire ; sinon l'app propose le cours à reprendre.
- La maîtrise du domaine devient un indicateur circulaire compact.
- Le changement d'univers reste replié et affiche, une fois ouvert, des cartes avec miniatures réelles lorsqu'elles existent.
- La logique Smart Memory / RC22 est utilisée directement dans ce nouveau renderer au lieu de dépendre des anciens sélecteurs `.hd219-*` qui n'existaient plus dans Visual V4.
